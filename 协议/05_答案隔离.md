# 答案隔离规则 v1

学生可见的 `题库/` 只含题面、必要前提和公开作答要求。标准答案、推导、评分点、预期错误、目标机制、审查记录、题目生成提示与未投放变体放到 `教师私有/`（本地 Git 忽略）或单独的受限教师仓库。公开仓库的隐藏目录、不同分支、未链接文件、Git LFS 或删除后的 Git 历史都不能当隔离措施。

投放给 ChatGPT 时，独立作答前只提供学生题面与必要学习状态，不提供教师材料。若 ChatGPT 已见答案或决定性机制，应由它明确记录污染范围，改用机制不同或经审查的新题。若用户已见答案，原题后续可用于巩固，但不当作未见题的独立证据。

提交前检查 staged 文件名与内容，尤其是答案关键词、教师路径、脚本测试数据和生成日志。若答案误入远端，标记相关题已曝光/污染，停止用于独立测量；再处理仓库访问与历史，不仅删除当前文件。不要把私钥、账户密钥或个人聊天原文未经选择地上传。
