# 学习记录

`事件.csv`保存发生过的曝光、作答、反馈、迁移和间隔检索；原文可在 `原始作答/` 按 event_id 独立保存。`当前状态.csv`和`复习队列.csv`是由事件推导的工作视图，可校正但不得替代事件。初始文件仅含表头，表示尚未迁入证据。

已接收[历史学情基线 v0](历史基线/HB-20260920-001.md)。它保留教学 GPT 的历史回顾与证据线索，不充作原始作答；三张 CSV 仍仅有表头。后续可补查旧证据，也可从正常学习回合开始追加新事件，不要求整章重考。

对错误保留用户当时的真实表达，不替其润色。Error Log 仅收复发、高信心、稳定模型等值得长期追踪的独立错误；AI 错误、笔误、OCR 错误或连锁结果通常不收。
