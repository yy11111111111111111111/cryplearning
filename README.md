# 密码学学习仓库

本仓库把三类东西分开：`知识/`保存经过核验的“是什么”，`题库/`测试“能否调用”，`学习记录/`保存真实作答与复习证据。规划、讲解、AI 生成或题目通过检查都不等于学习者掌握。

从 [总入口](00_总入口.md) 开始。本仓库对应公开 GitHub 仓库 `yy11111111111111111111/cryplearning`；目前是协作与记录框架，尚未投放题目。

| 区域 | 用途 |
|---|---|
| `知识/` | 已核验的定义、对象关系、条件、推导与来源；不收未经确认的掌握结论 |
| `题库/` | 学生可见题面与投放要求；不放答案、考点标签或审查记录 |
| `学习记录/` | 原始作答、曝光、反馈、迁移、间隔检索和复习队列 |
| `路线/` | 全局路线与当前局部节点；建议和已实施状态分开 |
| `协议/` | 三方职责、出题、证据、状态和答案隔离规则 |
| `交接/` | 三方交接模板与当前交接 |

教材 PDF 和聊天记录不自动复制入仓库。引用时记录版次、章节、页码或可核验链接。`教师私有/` 被 Git 忽略，不能靠公开仓库中的隐藏目录、分支或 Git 历史隔离答案。
